# 智座星野 - 图书馆座位智能预约系统

## 1. 24小时永久云端网址（随时随地访问，无需开电脑）
- **公网访问网址**：[https://erhai6.pythonanywhere.com](https://erhai6.pythonanywhere.com)
- 适配手机端（微信/手机浏览器）、平板与电脑端，支持 4G/5G 移动流量直接访问。

## 2. 默认登录账号

| 角色 | 账号 | 初始密码 | 说明 |
| :--- | :--- | :--- | :--- |
| **学生端** | `student1` | `123456` | 楼层选座、预约、签到、暂离、违规记录查看 |
| **管理员端** | `admin1` | `adminpwd` | 数据大盘监控、预约筛选、黑名单管理、违规清零、AI监控 |

> 也可以在登录页点击「立即注册」自由注册新的学生账号。

## 3. 本地运行（如需离线调试）
- 双击 `一键启动(本地电脑运行).bat` 启动本地服务，访问 `http://127.0.0.1:5000`
- 双击 `一键停止(本地电脑运行).bat` 停止本地服务
